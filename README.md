# VidaLoom

Browser-based local-first video composition app.

## Tech Stack
- **Framework:** React 19, TypeScript, Vite
- **Preview & Export:** Remotion Player, `@remotion/web-renderer` (pinned to 4.0.544)
- **Media Processing:** Mediabunny
- **Audio Analysis:** Web Audio API
- **State & Validation:** Zustand, Zod
- **Testing:** Vitest

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run tests
npm test

# Build for production
npm run build

# Lint code
npm run lint
```
